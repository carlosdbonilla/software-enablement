# AWS Cloud Practitioner Essentials – Study Notes

Lesson-by-lesson notes for the **AWS Cloud Practitioner Essentials** course (13 modules, AWS Skill Builder / Coursera), written to ramp up on AWS for a **Databricks Solutions Architect** role.

Every module follows the same layout:

- **Lessons line** + headings that match the course's own lesson titles, in order
- Key concepts, comparison tables, and analogies for each lesson
- **🎯 Databricks SA Connection**: how each AWS concept shows up in Databricks customer conversations
- **📝 Exam / Interview Quick Hits**: the one-liners to memorize

## What's changed since the course was recorded (as of late 2026)

The notes teach what the course teaches, and flag these with **⚠️ 2026 update**:

| Topic | Change |
|---|---|
| Free Tier (Module 11) | Since July 15, 2025: up to $200 in credits and a 6-month free plan for new accounts |
| Support plans (Module 11) | Developer, Business, and Enterprise On-Ramp end Jan 1, 2027 → Business Support+, Enterprise Support, Unified Operations |
| Migration tools (Module 12) | Migration Hub and Application Discovery Service closed to new customers Nov 7, 2025 → AWS Transform |
| Snow Family (Module 12) | Snowball Edge existing customers only since Nov 7, 2025; Snowcone discontinued; Snowmobile retired |
| QLDB (Module 7) | End of support July 31, 2025 |
| QuickSight / Amazon Q (Module 8) | QuickSight is now part of Amazon Quick |
| AppStream 2.0 (Module 13) | Renamed Amazon WorkSpaces Applications |

## How to use these notes

1. Watch each lesson, then read the matching section here
2. Add anything the video covers that the notes don't
3. Review the **Quick Hits** before the module assessment
4. Rehearse the **Databricks SA Connection** bullets out loud. That's the part interviews test
