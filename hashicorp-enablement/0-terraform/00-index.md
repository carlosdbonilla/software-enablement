## How to study (so it sticks)

Every lesson has the same shape:

1. **🎯 Goal** — what you're learning
2. **💡 The Idea** — plain English + a real-world analogy
3. **🔑 Key Terms** — the words you must know
4. **🧪 Try It** — hands-on (doing beats reading)
5. **⚠️ Watch Out** — common beginner mistakes
6. **🧠 Recall** — answer *without looking*, then check

**Three habits that make it stick**

- **Type the code, don't copy-paste it.** Your fingers learn the syntax.
- **Answer the Recall questions out loud before opening the answers.** Struggling to remember is what builds memory.
- **Review on a schedule** (below). Short reviews spaced out beat one long cram.

## Review schedule

| When | What |
|---|---|
| Same day | Re-answer that lesson's Recall questions |
| Next day | Read the [Review Sheet](11-review-sheet.md), answer its flashcards |
| 1 week later | Flashcards again + rebuild lesson 3's project from memory |
| 1 month later | Flashcards + rebuild the [AWS project](10-aws-project.md) without notes |
